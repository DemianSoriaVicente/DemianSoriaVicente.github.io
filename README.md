# Demian Soria Vicente — Portfolio & résumé

🇬🇧 English · [🇪🇸 Español](#español)

Personal website of Demian Soria Vicente (web developer · AI & automation · IT support): profile, services, experience, education, tech stack and a contact form. Available in Spanish and English.

🔗 **https://demiansoriavicente.github.io/** (ES) · **https://demiansoriavicente.github.io/en/** (EN)

## Features

- Static site: plain HTML, CSS and vanilla JavaScript, no framework or build step
- Light/dark theme (remembered in the browser) and respect for reduced-motion settings
- Self-hosted fonts (Bricolage Grotesque, JetBrains Mono)
- Contact form sent through [Web3Forms](https://web3forms.com); the site stores nothing
- SEO: canonical and `hreflang` tags, Open Graph and X cards, JSON-LD, sitemap and `robots.txt` (100/100 on TagScope)

## Structure

```
index.html      Spanish page (root)
en/index.html   English page
main.js         Theme, animations and contact form
styles.css      Styles
assets/         Fonts and images
```
